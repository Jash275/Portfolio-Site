# Third-party icon sources

- Project detail and card icons: Lucide, included through the existing `react-icons/lu` package. Lucide is ISC licensed: https://github.com/lucide-icons/lucide/blob/main/LICENSE
- Existing social and generic UI icons: BoxIcons via the existing `react-icons/bi`, `react-icons/hi`, and `react-icons/rx` sets. BoxIcons is MIT licensed: https://github.com/box-icons/boxicons/blob/master/LICENSE
- The navigation icons use Heroicons (MIT): https://github.com/tailwindlabs/heroicons/blob/master/LICENSE
- The menu icon uses Radix Icons (MIT): https://github.com/radix-ui/icons/blob/master/LICENSE
- The copy confirmation icon uses Remix Icon (Apache-2.0): https://github.com/Remix-Design/RemixIcon/blob/master/License
- The site monogram, cube art, favicon and Open Graph image are original local SVG/raster assets in this repository.
